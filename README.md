# Layali Restaurant

Webové stránky fiktivní restaurace **Layali** s arabskou kuchyní, Brno.

## O projektu

Jednoduchý statický web v češtině: úvodní stránka, jídelní lístek, kariéra a kontakt s mapou.

## Struktura

| Soubor | Popis |
| --- | --- |
| `index.html` | Úvodní stránka |
| `menu.html` | Jídelní lístek |
| `kariera.html` | Kariéra |
| `kontakt.html` | Kontakt a mapa |
| `layali.css` | Styly webu |
| `*.png`, `*.svg` | Obrázky a logo |

## Technologie

- HTML + CSS
- Google Fonts (Bodoni Moda)
- Google Maps (embedded)

## S čím pomohlo AI

- výběr písma (font) a barevného ladění,
- tvorba kontextů (název, hlavní obsah, fiktivní informace),
- vygenerování loga,
- úprava rozlišení obrázků,
- nastavení obrázku na pozadí.
